## ⚠️ Note

The game creates a file called `game-pref.txt`. If you already have a file with this name, please move or rename it before running the game.

---

## 📦 Installation

### Step 1 — Requirements
You need `python3` (or newer) installed on your machine.

### Step 2 — Clone the repo
```bash
git clone https://github.com/madsoverby/Terminal-spil.git
```

### Step 3 — Run the game
```bash
python3 main.py
```
or
```bash
python main.py
```
